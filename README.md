# Prompt-Engineering
Write a bedtime story about a bat who is afraid of dark for children aged 5 to 7.

## AIM:
Write a bedtime story for children aged 5 to 7 using Large Language Models.
## ALOGORITHM:

STEP-1: State the goal of the story (genre, tone, length, constraints).
STEP-2:Write the base prompt with all requirements.
STEP-3:Submit prompt to Gemini AI and obtain the output.
STEP-4: Check against criteria (coherence, creativity, style, constraint satisfaction).
STEP-5: Note any weaknesses or missing elements.
STEP-6: Modify wording, add constraints, or give examples to address issues.
STEP-7: Submit the refined prompt and collect new output.
STEP-8: Score the new story and compare with the previous one.
STEP-9: Continue refinement until the story meets quality goals.
STEP-10: Save the best version along with parameters used.
